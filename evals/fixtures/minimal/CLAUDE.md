# Project rules

## What this project is
A small single-user web app. Nothing has been built yet.

## Stack
- Vite + React + TypeScript
- Vitest + React Testing Library
- Data saved in the browser's localStorage — no backend, no login

## Rules
- Specs live in `specs/NNN-slug/`. Build only what the approved spec asks for.
- Anything in a spec's "Out of scope" section must not be built.
